# AI-Powered Sales & Revenue Forecasting and Business Intelligence Platform

An end-to-end business intelligence and machine learning platform built using the UCI Online Retail dataset.

## Project Status

Currently in Phase 1: Dataset Understanding.

## Technology Stack

- Python
- Pandas
- NumPy
- Django
- Django REST Framework
- React
- XGBoost
- SQLite
- Scikit-learn

## Dataset

This project uses the UCI Online Retail dataset.

Official source:

https://archive.ics.uci.edu/dataset/352/online%2Bretail

The original dataset is not committed to this repository.
